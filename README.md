# LeadFlow CRM

A production-inspired CRM backend built with Node.js, Express, MongoDB, and JWT Authentication.

## Features

- JWT Authentication
- Role-based Authorization
- Lead Management
- Lead Assignment
- Lead Workflow
- Notes
- Soft Delete & Restore

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Cookie Parser

## Project Structure

src/
├── controllers/
├── services/
├── models/
├── routes/
├── middlewares/
├── utils/
